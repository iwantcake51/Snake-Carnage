# Snake: Carnage

Browser game, plain HTML/CSS/JS, no build step to develop or test. Deployed with Netlify, which runs `tools/bundle.mjs` (see `netlify.toml`): it joins the `js/NN-*.js` scripts listed in `index.html`, in order, into one content-named `js/app.<hash>.js` (01-config's `'use strict'` dropped, the sound manifest inlined as `SOUND_MANIFEST`), names the stylesheet the same way and rewrites `index.html`, so a visit is a couple of requests; `_headers` lets browsers keep both for good. Never commit its output (`.gitignore`), and keep every game script a plain `<script src="js/...">` tag in `index.html` so the bundler finds it.

## Rules for every change

1. **Bump the version by exactly 1.** `GAME_VERSION` sits at the top of `js/01-config.js` (e.g. `'1.3'` → `'1.4'`, `'1.9'` → `'1.10'`). Bump it once per change/PR, not once per commit. It shows in the bottom-left of the main menu.
2. **Levelling changes reset everyone's levels.** Whenever a change touches levelling (the XP curve `xpNeed`, what pays XP, how tokens come from levels), bump `LEVEL_V` in `js/38-upgrades.js` by one in that same change: every save then starts over at level 1 with no XP and an empty skill tree (chips, cosmetics, achievements and records are kept), and the player is told why.
3. **Ship through a pull request.** Commit to a feature branch, push, and open a PR into the default branch (or update the open one) so Netlify builds it. Don't push straight to the default branch.

## Layout

- `index.html`: the page. It loads `css/style.css`, then `js/01-…js` to `js/NN-…js` **in numeric order**. There's no bar above the board: the in-run stats (`#hudbar` in `#hudHi`: time of day top-left; score, best, chips, level and pause top-right, right above the combo) sit on it, and hide outside a run (`frame` in 34-render).
- `02-progression` holds the level curve (`xpNeed`: slow from the start, a first game reaches about level 5) and `gainXP`; each kill's XP grows with how long your body has lived (`snake.lifeT`, up to +60% at ten minutes) and a bigger combo pays a little more XP and chips (+2% a step, up to +30%), both in `eatReward` (22-snake). When a run ends, `paySurvival` adds a survival bonus for every full minute alive (`run.aliveT`; `SURV_BONUS`: later minutes pay more), shown first under Unlocked on the summary (in multiplayer, a notice when the round ends).
- Nothing on the page can be selected or copied by accident: a global `user-select:none` at the end of `css/style.css`, with inputs, textareas and editable text let off.
- `03d-game-icons` holds every skill, ability, stat and notification icon from game-icons.net (CC BY 3.0, credited in Settings › Controls) as path data in `GI`; `giSvg(name)` draws one. Add new icons there, not as emoji.
- **Icons for the skill tree always come from game-icons.net** (https://game-icons.net). Whenever a node is added or needs a new icon, pick a fitting one there and never hand-draw it or use an emoji. The same set ships as the npm package `@iconify-json/game-icons` (its `icons.json` holds every icon's `body`, 512 x 512), which works where the site itself is blocked; the GitHub repo `game-icons/icons` has the raw SVGs. Copy the icon's path data into `GI` under the node's `icon` key (drop any `fill="currentColor"`: `giSvg` sets it), with the icon's game-icons name in a comment, and `upIcon` picks it up for the tree, the details panel, the ability HUD and the touch buttons. a downed player's respawn spot is picked when they go down (`netSpawnPoint`: a long clear run ahead, room for the body behind, away from bombs, fire and gas) and shown to them as a pulsing outline (`drawSpawnGhost`, on its own canvas `#spawnFx` above the death tint)): `40c-net-core` (connections, lobby, modes and teams, reconnects, host migration), `40d-net-sync` (the shared world, lives pools, round clock) and `40e-net-ui` (host or join, the party panel on the main menu, the lobby in the run setup's layout, name tags, score panel, scoreboard; the in-run score panel `netHud` is built once and updated in place (`netHudRow`, `netHudOrder`), so its animations play once; every score in it (players, teams, the co-op total) rolls like a slot machine (`slotSet`: a reel per digit, a changed digit spins a full turn forward and lands, left to right, with a gold flash; transform only; Reduced motion just changes it): lives are a row of game-icons hearts (`netHeartsSync`; one lost turns into Kenney's broken heart, which shakes in and stays dimmed), a downed player's name and score are crossed out with Kenney's skull shaking in beside them, it sits under the top-right stats and the combo (`netHudPlace`), and your own death banner (`netDownBanner`) and comeback (`netBackLives`) show the lives left).
- `js/editor/*.js` is the map editor itself. It is not in `index.html`: `40b-editor-runtime.js` loads it on demand, on desktop only (`EDITOR_FILES` lists it in order). `editor.html` is its standalone entry point. `ed-qol.js` loads last and wraps ed-core's functions for the quality-of-life layer: command palette (Ctrl+K), smart guides, hover labels, smooth camera, clipboard for every kind of item, named undo, autosave, the prop scatter brush, number scrubbing, and the prop editor's zoom, handles and snapping. `ed-build.js` loads after ed-core and before ed-qol and adds the building tools by wrapping the editor's pointer, key, tool and panel hooks. The tools are the random Prop brush (J: random props from a picked set inside the brush, kept apart by their sizes plus a gap, never inside walls; Alt erases; `[ ]` sizes it), Room (R: four walls with a doorway on a chosen side and an optional floor area), Wall line (I: click points, Shift snaps to 45°, double-click or Enter ends it, clicking the first point closes the loop) and Doorway (D: cuts a gap in the wall clicked). It also gives a selected rect or circle a Material (`o.mat`, painted over it by `drawObstacleUpright` in 40b, with New and Edit buttons into the material editor), lets the floor's base be one material across the whole map (`'mat:'+id`, `paintBase` in 05d), and draws the select tool's rotate ring, arrows and handles (`edGizmoDraw`, `edDrawHandles` in ed-core). It also gives the prop editor a resizable Before panel and Shift+click multi-select (`PE.multi`): a change to the main part carries to the others, so position and rotation move by the same delta, size scales by the same ratio and everything else is copied.
- `03e-sprites` loads `sprites/kenney.png`, one atlas of the Kenney sprites the game uses (`tools/kenney-atlas.py` packs it from the zips in `kenney/`; the names in `KSPR_NAMES` follow its order). They're white and grey, so `kTint(name, color)` colors one and caches it, and `kDraw` draws it or returns false so the caller draws its own look instead: everything that uses them (smoke and soot, blast fireballs and flash, crater fires, strafing-round flashes, the scorch and thrown dirt, autumn leaves, falling leaves, low plants and spring petals on grass, water caustics through `kPattern`) keeps a procedural fallback, used until the atlas loads and always on `file://` (a file image would taint the floor canvases the game reads back). Light masks from the atlas are laid into the light sprites in place with `kModulate` once it loads (`kReady`): flashlight `BEAM`, the lamps' `MASK_SPR`, and `WIN_SPR` for light falling out of windows.
- `38h-cinematic` makes danger read on screen, cheaply: a bomb about to land near you darkens the screen's edges (`cineIncoming`), a close blast punches them dark red, gas breathes a green edge, burning flickers an orange one; four fixed gradient layers in `#cinefx` changed only through opacity, no letterbox bars (those are the intro's).
- `38g-cluster-fire` also holds gas bombs (kind `g`: `gasPop` goes off with a dull bang and a bubble of gas (`gasBubbles`: a Kenney smoke ring and bubble skin) swelling out of the middle, then a seeded cloud of `gasPuffs` rolls out from the centre (`gasAt`) and drifts and fades over ~15 s, drawn from Kenney's smoke and twirl particles (`K_GAS`, `K_TWIRL`) with wisps curling off it (`gasWisps`), and leaves stains on the ground (`gasStains`, drawn under everyone, fading over most of a minute); breathing it (`gasK`, from where your head is) slows you (`gasSlow`, cut by Battle Hardened, id `skull`, which only makes it wear off sooner, `SKV.stunCut`) and blurs, sways and drains the screen and lets TV static creep in (`gasScreen`, `drawGasEdge`), and while you're in it you can't make out any outlines or the bomb, strafe and bomblet markers (`GAS_SEE`: gone in a moment, back over a few seconds once you're clear; the falling bombs themselves still show), all of which the Gas Mask node (id `mask`) removes except the slowdown; no notice on screen: the screen itself says it; people and animals in it just walk at under half speed (`c.gasT`) and cough (`Sfx.cough`), host only).
- `38g-cluster-fire` holds cluster bombs (a strike of kind `c`: it goes off like a plain bomb, full blast and heavy props included, and throws out 4-6 bomblets whose bouncing paths are worked out at once from the strike's seed, `simBomblet`, so every screen has the same ones, each landing spot marked until its own random fuse goes (in no set order, never two at once) and a small blast, `detonate` with `mini`), incendiaries (kind `i`: a smaller blast and 4-6 small, temporary fire patches, `firePatches`) and burning: touching fire sets your snake alight (`burnTick`, one clock however many patches you touch), every 0.7 s a piece of the tail burns off with charred bits and blood (`burnDamage`, `brn` to the others), down to `BURN.min`, after which the next tick kills (`deathBy` 'fire'); it burns on for 1.2 s after you get clear, and water puts it out at once (`nearWater`). The look and sound of burning (flames and embers on the body, the orange edge glow `drawBurnEdge`, heat haze rippling in from all four edges of the screen `drawBurnHaze` (each edge band copied once at half size, its rows slid on a climbing wave and faded toward the middle, so no seam and no full-frame copy), flames licking up the bottom and lower sides of the screen `drawBurnFlames` (a dozen cached Kenney flame sprites added on, with a teardrop stand-in before the atlas loads; nothing built per frame), the heat shimmer `drawBurnHeat`, drawn under the markers and the HUD, and the crackle `Sfx.burnSizzle`) follow `burnK` and the effects settings, and `fireFrame` clears it all whenever you're not alive in a run. People keep clear of fire and burn in it (`fireCrowd`, host only).
- `03g-anim` is the animation registry: `ANIM_DEFS` lists every tunable animation (people's legs, arms and bob, animal gaits and tails, the snake's slither, trees, grass, plants, weather, water, fire, smoke, gas, lamps, flesh chunks) and `AN[id]` its knobs (`sp` speed, `amp` amount, `freq`), 1 as designed, saved per browser. Drawing code reads `animT(id)` (that animation's clock) and `AN[id].amp`; a function with one animation shadows `T` with `const T = animT(id)`. Add a new animated thing there and wire it the same way. `40g-anim-editor` is the Animation editor (Settings › Display, the admin panel, the map editor's Ctrl+K): a floating panel with sliders, a live creature preview and copy/paste.
- `03f-kenney-icons` holds Kenney's menu, shop, lobby and score-panel icons (the broken heart and the skull) as path data in `KI` (`kiSvg(name)` draws one, filled in the text color), written by `tools/kenney-icons.py` from the zips in `kenney/`: the main menu's icons, locks and checkmarks, lives hearts and the winner's crown. The HUD clock and the season badge use game-icons.net's sun, sunset, moon, lamp and season icons from `GI`.
- **Textures and particle effects come from the Kenney packs in `kenney/` wherever one fits.** Before drawing smoke, fire, sparks, dust, gas, magic, debris, foliage, light pools or ground textures by hand, look through the packs (`kenney_particle-pack.zip` alone has smoke, fire, flames, sparks, stars, twirls, magic, traces, scorch, dirt and circles); add the sprite to `NAMES` in `tools/kenney-atlas.py` and to `KSPR_NAMES` in `03e-sprites` in the same order (append, so existing indices stay put), rerun `python3 tools/kenney-atlas.py`, and draw it with `kDraw`/`kTint` tinted to suit, keeping a procedural fallback for before the atlas loads. Hand-drawn canvas shapes are for things no pack covers.
- `05e-ground-tex` lays photo ground textures from `textures/ground/` (copied out of `texture-packs/`): `groundTex(x, set, seed)` fills the floor with a set's first texture, then each of the others in large soft noise patches, every layer at its own random angle and offset so the tile grid never shows, with a faint broad light and shade; each world build rolls a new one. Sets in `GTEX.sets` (how much each further texture covers in `GTEX.cover`): Open Field `meadow` (`fieldGround` adds its mowing stripes and verge), Meadow `wild`, Park `lawn`, Farm `pasture`, the Moon `moon` (grey regolith) and Mars `mars` (rust-red rock), graded to each map's colors when copied; Town is ambientCG's photo textures (`GTEX.scale` lays these finer ones smaller): `walk` plain concrete on every sidewalk, no slab grid (Town's `ground`, so a wide map's strips share it), the forecourt and driveway aprons (tinted darker and lighter), `road` on every street, its tyre streaks run along the street (`texShape`'s `ang`: only that way or reversed), the same road laid again over each junction so no curb crosses it, quiet streets a shade darker, and `lot` cracked asphalt in the parking lots and yards; the centre lines, stop lines, zebras and parking bays are painted over it as before; `dirt` fills every `dirtTrails` trail (Open Field, Meadow, the Farm's yard roads, which are wandering trails, and the trails carried into wide strips), Park's paths and the Meadow campsite; `soil` the Farm's crop field, `mud` its pig pen. A map's `ground(x)` (`mapGround(x, set)`) lays its set across the whole width before a wide map's strips and middle are painted, and `GTEX.drawn` tells the strips and the map's own floor it's already down (only while that floor is being built), so they skip their stand-in; `texShape(x, set, mask, seed, ang)` lays a set inside a shape (the mask is drawn whole, then cut once; every shape on one floor shares one ground per set, always built the whole floor's width: `GTEX.ox` says how far a wide map's middle is shifted while it draws in its own coordinates, so it lines up with the strips); `craters(x, n, null, seed)` draws see-through craters on a real ground. It draws nothing until the images are in, and never on `file://`, so every map keeps its procedural ground as the stand-in; once they're in, `groundTexReady` redraws the cached menu pictures, the map browser's one at a time in the background (never set `thumbs` to null: the browser and `selectMap` read it at any moment). Grass tufts and the low plants blend into it: each tuft takes its color from the season-graded ground it grows in (`grassColAt`), a little toward the season's blades (`grassShade` in 24-creatures: a darker root, a lighter tip, a soft contact shadow, rounded to a few shades so the field is still a handful of strokes; a blast's charred tufts set `cb`/`ct` themselves), and each plant is a shade deeper than its ground with its shadow cast down-right (`drawPlants`). Keep the textures green enough for `buildGrassMask` (green over red by 18 and over blue by 25), or tufts, seasons and burnt grass lose them.
- `texture-packs/` holds texture packs the owner sends, as `.rar` (or `.zip`, `.7z`) archives, one per pack: a source library like `kenney/`, deleted by `tools/bundle.mjs` before Netlify publishes. Open a `.rar` with `node-unrar-js` (npm; no system tool needed), copy what the game uses to where it's loaded from, sized for the game, and list it in `texture-packs/README.md`.
- `kenney/` holds [Kenney](https://kenney.nl/assets) packs (CC0), zipped or extracted, one per pack, to pick sprites and sounds from. It's a source library: `tools/bundle.mjs` deletes it before Netlify publishes, so copy any file the game uses to where it's loaded from (audio to `sounds/` plus `sounds/manifest.json`) and load it from there, never from `kenney/`.
- `js/vendor/` holds third-party code (PeerJS, loaded only when co-op opens).
- Co-op is host-authoritative (`docs/MULTIPLAYER.md`). Code that changes the world (spawning, deaths, panic, noise, scoring the crowd) must run only where `AUTH()` is true (the host, or single player); guests get it from the host. Keep single player working without co-op.
- `docs/MAP_DESIGN.md` holds the per-map layout plan and rules; keep it in step when a map's layout changes.
- `41-boot.js` must stay last: it builds the first menu and starts the frame loop after every other file has loaded.

## Testing

No test suite. Open `index.html` in a browser, or drive it headless with Playwright (Chromium is preinstalled in Claude's cloud env). Check that a night run has no console errors, then look at a screenshot.

For performance, turn on Settings › Display › Performance stats (or press F3 in a run). Full mode times the game's own code per part; "Find what's slow" switches each part off for a moment and measures what it really costs, graphics chip included. The pause screen's Performance tab (and Performance in the multiplayer menu) reports the run so far from an always-on recorder: frame-time breakdown, the worst hitches with what was happening (kills, smashing, how much blood and debris), and likely causes. Headless Chromium renders the canvas in software, so its frame times don't reflect a real GPU.
