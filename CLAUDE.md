# Snake: Carnage

Browser game, plain HTML/CSS/JS, no build step to develop or test. Deployed with Netlify, which runs `tools/bundle.mjs` (see `netlify.toml`): it joins the `js/NN-*.js` scripts listed in `index.html`, in order, into one content-named `js/app.<hash>.js` (01-config's `'use strict'` dropped, the sound manifest inlined as `SOUND_MANIFEST`), names the stylesheet the same way and rewrites `index.html`, so a visit is a couple of requests; `_headers` lets browsers keep both for good. Never commit its output (`.gitignore`), and keep every game script a plain `<script src="js/...">` tag in `index.html` so the bundler finds it.

## Rules for every change

1. **Bump the version by exactly 1.** `GAME_VERSION` sits at the top of `js/01-config.js` (e.g. `'1.3'` → `'1.4'`, `'1.9'` → `'1.10'`). Bump it once per change/PR, not once per commit. It shows in the bottom-left of the main menu.
2. **Ship through a pull request.** Commit to a feature branch, push, and open a PR into the default branch (or update the open one) so Netlify builds it. Don't push straight to the default branch.

## Layout

- `index.html`: the page. It loads `css/style.css`, then `js/01-…js` to `js/NN-…js` **in numeric order**. There's no bar above the board: the in-run stats (`#hudbar` in `#hudHi`: time of day top-left; score, best, chips, level and pause top-right, right above the combo) sit on it, and hide outside a run (`frame` in 34-render).
- `03d-game-icons` holds every skill, ability, stat and notification icon from game-icons.net (CC BY 3.0, credited in Settings › Controls) as path data in `GI`; `giSvg(name)` draws one. Add new icons there, not as emoji.
- **Icons for the skill tree always come from game-icons.net** (https://game-icons.net). Whenever a node is added or needs a new icon, pick a fitting one there and never hand-draw it or use an emoji. The same set ships as the npm package `@iconify-json/game-icons` (its `icons.json` holds every icon's `body`, 512 x 512), which works where the site itself is blocked; the GitHub repo `game-icons/icons` has the raw SVGs. Copy the icon's path data into `GI` under the node's `icon` key (drop any `fill="currentColor"`: `giSvg` sets it), with the icon's game-icons name in a comment, and `upIcon` picks it up for the tree, the details panel, the ability HUD and the touch buttons. Look at it at node size (21-30 px) before keeping it. Keep the credit line in Settings › Controls if you add icons by new authors.
- The JS files are classic scripts that share one global scope. Load order matters for top-level code, so when you add a file, give it a number in the right spot and add its `<script>` tag to `index.html`.
- One system per file: `05-maps`, `13-challenges` (map challenges), `14-modifiers`, `17-sound` (Web Audio; `Sfx.hold` freezes the world's sound while paused or on the solo death screen, menu clicks go through their own context), `18-time-of-day`, `19-light-shadows`, `20-flashlights`, `23-giblets`, `25-dialogue`, `26-creature-ai`, `27-crowds`, `29b-skins` (every snake skin: markings painted in body space, u down the body in body radii and v across it, so bands wrap round, saddles bend and the tail's markings shrink with the taper; each skin has a ground color `base` and a `paint` for its markings, every color from the player's two colors (the two themselves, mixes between them where a skin needs more tones (`hslPath` blends round the color wheel so they stay vivid), and shades of those; never a fixed palette); the ground blends from segment to segment; noise skins (`tex`: Lava, Galaxy, Plasma, Obsidian, Blood Soaked, Lunar, Martian) fill the ground with a body-space noise texture built once per skin, colored once per color pair, mapped onto each band as two exactly placed triangles so it bends without seams, and it can flow down the body), `30-input` (keyboard, mouse and touch; key bindings live in `BIND_DEFAULT`, and Settings › Controls rebinds them into `SETTINGS.keys`; the Mouse steering setting (`SETTINGS.mouseSteer`) aims the snake at the cursor every frame at the keys' turn rate, left click lunges, a key steers until the mouse moves again), `31-ui-menus` (the main menu: Home and Run setup are two views of one screen (`menuView`, `menuGo`), the map browser opens over the setup, `selectMap` updates everything in place; every menu screen sits on a still of the selected map (`mapArt`, cached, shown in `#menuArt`), never the live world; plus the Modifiers panel and the Settings tabs in `SETTING_TABS`), `33-update` (main update loop), `34-render` (render and frame loop), `35-notify` (notifications), `36-cosmetics` (shop catalog, lifetime achievements and their cosmetic rewards), `37-shop` (shop UI and custom color picker), `38-upgrades` (the skill tree's data: `SKILL_TREE` holds every node (three branches: Survival (senses, stealth, recovery: nothing that kills for you), Predator (anything that makes you deadlier: speed, Lunge, Hoover Mouth, Hiss, Wide Jaws, Bloodlust) and Fortune (more XP and chips: `SKV.xpK`/`chipK` are applied in `gainXP`, plus kill, challenge, near-miss, shop-price and end-of-run hooks); ranks cost skill tokens, one per level past 1 (`skTokens`: worked out from the level and the tree, never stored, so Reset tree just clears the tree; `PROG.tokBonus` holds what chip-bought skills were worth when the tree switched to tokens, `PROG.treeV` 3); majors unlock an ability or behavior, some behind a level (or a level per rank, like Battering Ram's three), passives have 3-5 ranks; an upgrade that only repeats is one node with ranks, never several nodes; prerequisites gate only the first rank), `sk(id)` is a node's rank as it counts right now (bought, switched on in `PROG.treeOff`, not cancelled by No skill tree / No abilities; in co-op `UPG_OVR` holds the other player's ranks), `SKV` turns ranks into every number the game uses (the details panel previews the same functions), `upg(id)` still answers the old tier questions; old `PROG.upg` saves migrate once through `treeFromUpgrades`, free, and `treeMerge` (`PROG.treeV` 2) folds the first tree's Quick Scales, Wrecking Ball and Siege Head into Speed Demon's and Battering Ram's ranks; abilities (Lunge, 3rd Eye (id `scent`), Camouflage, Hiss, Hoover Mouth), battering ram, the `NET` multiplayer hook; 3rd Eye runs a danger-weighted Dijkstra from the head on a 16 px nav grid built from `solidGrid` five times a second (bomb markers and unshot strafing lanes are costly to cross) and draws escape, lifeline, gold, crowd and meal trails; its Focus slows the world through `timeScale()` in the frame loop, solo only; `edgeFxTick` sets `EDGE_K`, from which the canvas blurs the edges (`lungeEdges` in 34-render: the frame halved step by step once a frame by `edgeShrink` and scaled back up, never a CSS backdrop blur or a page layer, and it reads the screen itself, so a lunge never forces the scene through an off-screen copy) and draws the Focus tint and lunge speed lines (`lungeLines`); the lunge's after-images (`dashGhosts` in 29-snake-draw) are each painted once, when taken, into a small low-resolution canvas (the stretch back up is the blur) and stamped every frame after that: never a canvas `filter` per frame, and the night rim doesn't trace them), `38f-skill-tree` (the Skill Tree screen: a board you drag, pinch and zoom with Fit tree and branch focus, nodes and S-curve links drawn from `SKILL_TREE`'s x/y, a details panel that never moves; buying updates the nodes, links, chips and panel in place, never a rebuild), `39-progress` (permanent and secret challenges), `40-summary` (end-of-run summary), and so on. Newer ones: `09b-materials` (material layer stacks), `09c-vector-shapes` (editable drawn shapes), `09d-custom-maps` (custom map schema, migrations, compiler), `27b-hearing` (sound events and what people hear, used by Blind crowd), `40b-editor-runtime` (prop definitions and the editor's desktop-only entry), `07-world` (world build; `solidGrid` for collisions and `opaqueGrid`/`opaque()` for what blocks light, so flashlight beams stop at walls), `03b-workers` (Web Worker pool for pure number-crunching such as snow), `03c-dropdown` (turns every `<select>`, game and editor, into the themed ladder dropdown; the real select stays hidden and keeps the value), `35b-perf` (Performance stats panel: per-part frame timings and the "Find what's slow" test), `40f-admin` (the admin panel, ` or F10: god mode, speed, time, spawning, air strikes, chips; single player or the host only), `21b-bloom` (soft glow round props that light up), `38b-destruction` (what breaking a prop looks, sounds and feels like; glass and the prop editor's "When it breaks"; every smash's real chunks of the object, impact flash and shock ring, colored dust), `38c-airstrikes` (outdoor air strikes on the snake's path, and the Air raid modifier that starts them at once: bomb markers, strafing runs with their marked lanes, bombing runs (a string of bombs walked across your path), jets, blasts, chunks of the real ground thrown up, craters and scorch marks (`scorch` also runs `burnGrass`: grass tufts in a crater are gone, a ring round it is left as black stubble, the grass mask there is cleared and the ground charred, and `scorched` keeps the crater so nothing grows or settles in it for the rest of the run); explosion light at night, the shockwave warp, ear ringing, the jet fly-by and bomb sounds with Doppler and a sky echo; gas pumps that blow up when hit (`pumpBlast`: the full blast, fires and shockwave, but never kills you), a hit on the front 30% of the snake kills it (it bursts outward from where it was hit, in its own two colors; any death in multiplayer bursts too) while a hit further back only blows the tail off (`tailCut`: the piece bursts, and leaves `tailBits`, big glinting chunks any player can eat for 75% of what was lost, shared over the network as `tcut`/`beat` events; the stump is blunt, torn and bleeds, and heals as soon as you grow), with a red flash and pulsing vignette; `nearMiss` pays XP when a bomb lands or a strafing run tears past right next to you and you live, shown small in the world where it happened; each strike is decided a few seconds early and waits in `AIR.queue` while `airApproach` plays the jet coming in from miles off (network event `airj`); strafing runs come from any angle and pick a lane clear of your body and heading, and take at most one piece of you; normal games get fewer, smaller, unevenly spaced strikes than Air raid (about every 36 s, still 28 s or so late on, never under 10 s however many you kill, with longer lulls now and then), and very rarely a barrage instead (`barrage`: a distinct warning, then 9-13 bombs over about 3.4 s scattered round where you're heading with a gap left on one side, never within 4 minutes of the last and never on top of another strike, followed by a long quiet); salvos sometimes carry one cluster bomb or incendiary (38g); each salvo bomb guesses which way you'll go, a heading picked from a cone ahead (wider further out, leaning the way you're turning), so going straight is no longer a guarantee of where they land; each kind has its own marker (`drawStrikeMark`: a bomb's red crosshair and brackets, an incendiary's orange ring of flame with a flame at its heart, a cluster bomb's yellow-and-black hazard ring with a dashed circle as far as its bomblets scatter) and the bomb itself comes down at a slant along the jet's line with a motion trail (`drawFallingBomb`); compared with Air raid, which starts slow (about every 13 s) and climbs over five minutes to about every 4-5 s, then holds; every kill by any player brings the next strike closer (`airKillTick`: a person 1 s, an animal under half that and less the smaller it is; never under 3 s), and how hard each run is depends on the kills of the player it targets and their team (`airKills`); every strike event carries the host clock (`h`) so guests take off the transit time (`netLag`) and it lands at the same spot and moment on every screen; the Locked on modifier (`MOD.lockOn`, `LOCK()`) aims every strike straight down your path, lets each bomb marker slide after its target for its first 0.4 s (`tk`: the player it follows, resolved on every screen with `snakeOfPid`), and makes jets (`j.v`) and strafing rounds (`s.v`) faster and bombs fall quicker; the Bad Intel skill rolls 50/50 in `airSchedule` for each targeted player (`skOf` reads another player's ranks) and calls their strike off, `airx` telling them), `38d-fuse` (the Dead man's switch modifier, id `fuse`: a bomb wired to your combo that ticks down with it and goes off at your head if the combo runs out; it wraps `updateCombo`, `endCombo`, `die` and `drawCorpses`), `38e-audio` (recordings from `sounds/` listed in `sounds/manifest.json` take over from the synthesized sounds; the procedural fuse crackle and the extra layers on blasts, gore and crashes; see `sounds/README.md`), and multiplayer (co-op, free for all, teams): `40c-net-core` (connections, lobby, modes and teams, reconnects, host migration), `40d-net-sync` (the shared world, lives pools, round clock) and `40e-net-ui` (host or join, the party panel on the main menu, the lobby in the run setup's layout, name tags, score panel, scoreboard).
- `js/editor/*.js` is the map editor itself. It is not in `index.html`: `40b-editor-runtime.js` loads it on demand, on desktop only (`EDITOR_FILES` lists it in order). `editor.html` is its standalone entry point. `ed-qol.js` loads last and wraps ed-core's functions for the quality-of-life layer: command palette (Ctrl+K), smart guides, hover labels, smooth camera, clipboard for every kind of item, named undo, autosave, the prop scatter brush, number scrubbing, and the prop editor's zoom, handles and snapping.
- `03e-sprites` loads `sprites/kenney.png`, one atlas of the Kenney sprites the game uses (`tools/kenney-atlas.py` packs it from the zips in `kenney/`; the names in `KSPR_NAMES` follow its order). They're white and grey, so `kTint(name, color)` colors one and caches it, and `kDraw` draws it or returns false so the caller draws its own look instead: everything that uses them (smoke and soot, blast fireballs and flash, crater fires, strafing-round flashes, the scorch and thrown dirt, autumn leaves, falling leaves, low plants and spring petals on grass, water caustics through `kPattern`) keeps a procedural fallback, used until the atlas loads and always on `file://` (a file image would taint the floor canvases the game reads back). Light masks from the atlas are laid into the light sprites in place with `kModulate` once it loads (`kReady`): flashlight `BEAM`, the lamps' `MASK_SPR`, and `WIN_SPR` for light falling out of windows.
- `38g-cluster-fire` holds cluster bombs (a strike of kind `c`: it splits into 4-6 bomblets whose bouncing paths are worked out at once from the strike's seed, `simBomblet`, so every screen has the same ones, each landing spot marked until its staggered fuse goes and a small blast, `detonate` with `mini`), incendiaries (kind `i`: a smaller blast and 4-6 small, temporary fire patches, `firePatches`) and burning: touching fire sets your snake alight (`burnTick`, one clock however many patches you touch), every 0.7 s a piece of the tail burns off with charred bits and blood (`burnDamage`, `brn` to the others), down to `BURN.min`, after which the next tick kills (`deathBy` 'fire'); it burns on for 1.2 s after you get clear, and water puts it out at once (`nearWater`). The look and sound of burning (flames and embers on the body, the orange edge glow `drawBurnEdge`, the heat shimmer `drawBurnHeat`, drawn under the markers and the HUD, and the crackle `Sfx.burnSizzle`) follow `burnK` and the effects settings, and `fireFrame` clears it all whenever you're not alive in a run. People keep clear of fire and burn in it (`fireCrowd`, host only).
- `03f-kenney-icons` holds Kenney's menu, shop and lobby icons as path data in `KI` (`kiSvg(name)` draws one, filled in the text color), written by `tools/kenney-icons.py` from the zips in `kenney/`: the main menu's icons, locks and checkmarks, lives hearts and the winner's crown. The HUD clock and the season badge use game-icons.net's sun, sunset, moon, lamp and season icons from `GI`.
- `kenney/` holds [Kenney](https://kenney.nl/assets) packs (CC0), zipped or extracted, one per pack, to pick sprites and sounds from. It's a source library: `tools/bundle.mjs` deletes it before Netlify publishes, so copy any file the game uses to where it's loaded from (audio to `sounds/` plus `sounds/manifest.json`) and load it from there, never from `kenney/`.
- `js/vendor/` holds third-party code (PeerJS, loaded only when co-op opens).
- Co-op is host-authoritative (`docs/MULTIPLAYER.md`). Code that changes the world (spawning, deaths, panic, noise, scoring the crowd) must run only where `AUTH()` is true (the host, or single player); guests get it from the host. Keep single player working without co-op.
- `docs/MAP_DESIGN.md` holds the per-map layout plan and rules; keep it in step when a map's layout changes.
- `41-boot.js` must stay last: it builds the first menu and starts the frame loop after every other file has loaded.

## Testing

No test suite. Open `index.html` in a browser, or drive it headless with Playwright (Chromium is preinstalled in Claude's cloud env). Check that a night run has no console errors, then look at a screenshot.

For performance, turn on Settings › Display › Performance stats (or press F3 in a run). Full mode times the game's own code per part; "Find what's slow" switches each part off for a moment and measures what it really costs, graphics chip included. The pause screen's Performance tab (and Performance in the multiplayer menu) reports the run so far from an always-on recorder: frame-time breakdown, the worst hitches with what was happening (kills, smashing, how much blood and debris), and likely causes. Headless Chromium renders the canvas in software, so its frame times don't reflect a real GPU.
